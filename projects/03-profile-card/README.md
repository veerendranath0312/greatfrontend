# Profile Card Component

![Status](https://img.shields.io/badge/Status-Completed-success)

> A pixel-perfect solution to the "Profile Card" challenge from **[Great Frontend Projects](https://www.greatfrontend.com/projects)**.

## 📄 Description

A clean, reusable profile card component featuring an avatar, name, role, bio, a "Contact me" button, and social media icons.

- **Goal:** Build a component that matches the provided Figma design with high fidelity using only standard web technologies.
- **Challenge Source:** [Great Frontend - Profile Card](https://www.greatfrontend.com/projects/challenges/profile-card)

## ✨ Features

- **Pixel Perfect:** Matches the spacing, typography, and colors of the original design.
- **Social Icons:** GitHub, LinkedIn, Instagram, and X icons powered by Ionicons.
- **Pure CSS:** No frameworks or libraries—just clean, custom styles.

## 🛠️ Built With

- HTML5 (Semantic)
- CSS3 (Flexbox & Custom Fonts)
- [Ionicons](https://ionic.io/ionicons) (Web Components)

## 💭 My Notes

Although the challenge offered Tailwind as an option, I chose to use **vanilla CSS** to strengthen my understanding of the fundamentals.

- **Layout:** I used nested Flexbox containers with `gap` to stack the details and social links sections consistently.
- **Icons:** I used Ionicons' web component (`<ion-icon>`) to render the social links instead of custom SVGs.
- **Typography:** I imported the Noto Sans font from Google Fonts to match the design's typography.
- **Reset:** I implemented a minimal CSS reset to ensure consistency across browsers.
